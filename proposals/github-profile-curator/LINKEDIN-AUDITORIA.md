1. Headline não diz nem o que você faz hoje nem o que procura.
2. O "Sobre" começa com suporte, mas o post mais recente é de desenvolvimento — qual é o direcionamento?
3. Competências não incluem Node.js, SQLite, JavaScript, Git, testes ou API REST.
4. Seção Projetos vazia — o Cuco não está cadastrado como projeto no LinkedIn.
5. Dois posts idênticos sobre o mesmo trabalho de árvore binária publicados com 4 meses de intervalo.
6. "Disponível para" está vazio; nenhuma chamada clara para estágio/junior.
7. Rede de 39 conexões é pequena para uma busca ativa.
